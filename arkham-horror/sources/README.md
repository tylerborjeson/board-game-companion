# Arkham Horror sources

Authorized rules for this game. Do not add Campaign Guide text, card scans, or unlicensed scenario content.

## Standing corpus

1. **2021 Revised Core Set Learn to Play**  
   https://images-cdn.fantasyflightgames.com/filer_public/dd/78/dd7818fe-0c9a-4a6c-b685-e32ab55b1702/ahc60_learn_to_play_web.pdf
2. **ArkhamDB Rules Reference**  
   https://arkhamdb.com/rules

Learn to Play is the full gameplay foundation. Ingest the complete document at the start of a new session and verify it loaded. Use the Rules Reference as a targeted lookup, not a full ingest every time.

## Local copies

Put authorized PDFs in `pdfs/` (gitignored):

- `pdfs/ahc60_learn_to_play_web.pdf`

Prefer the local file when it exists. Otherwise fetch the official Learn to Play URL. Never commit the PDF or an extracted dump.
