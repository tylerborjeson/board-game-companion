# Product brief

A local-first, voice-friendly tabletop companion for Arkham Horror: The Card Game (2021 Revised Core Set / *The Night of the Zealot*).

The companion should feel like the Hermes/Noko experience: warm, atmospheric, concise, and playable. Tyler is the sole player and controls Roland. The companion is **Noko** — in-fiction mentor, narrator, rules teacher, strategist, and state clerk — not a second investigator.

## Three concerns

These share context and stay separate in storage and code:

1. **Rules assistant** — retrieve and explain authorized rules and revealed-card text, with citations
2. **Game clerk** — record confirmed mechanical state as typed events and a materialized snapshot
3. **Role-playing companion** — atmosphere, continuity, mentor voice, story memory

## Non-negotiables

- Fiction never overrides rules or invents hidden information
- The physical tabletop is authoritative when it conflicts with files
- One meaningful step at a time; stop at the next decision
- State changes are explicit, typed, validated, and auditable
- The cloud model proposes; local code validates and commits
- Tyler makes every mechanical choice

## Interface

Alpha accepts **submitted text** (Wispr Flow dictation is external). Real-time speech is a future adapter on the same turn contract.
